# Cosyte examples

Runnable end-to-end starters for the `@cosyte/*` healthcare libraries. Each
starter is a small, complete program you can clone, install and run in a
minute. Every message, document and image here is synthetic: generated by
`@cosyte/synth` or written by hand for the example. None of it is real patient
data.

The libraries themselves live in their own repositories and are documented at
[docs.cosyte.com](https://docs.cosyte.com).

Need it integrated? [Talk to us](https://cosyte.com/contact).
