# Cosyte examples

Runnable end-to-end starters for the `@cosyte/*` healthcare libraries. Each starter is a small,
complete program you can clone, install and run in a minute. Every message, document and image here
is synthetic: generated by `@cosyte/synth` or written by hand for the example. None of it is real
patient data.

The libraries themselves live in their own repositories and are documented at
[docs.cosyte.com](https://docs.cosyte.com).

## Starters

| Starter | Libraries | What it shows | Run |
| --- | --- | --- | --- |
| [deid-hl7](deid-hl7) | `@cosyte/deid`, `@cosyte/hl7`, `@cosyte/synth` | An HL7 v2 admit message run through the Safe Harbor policy, and the value-free manifest of what it removed or generalized | `cd deid-hl7 && npm install && npm start` |

## Run a starter

```bash
git clone https://github.com/cosyte/examples.git
cd examples/deid-hl7
npm install
npm start
npm test
```

Each starter needs Node 22 or later and nothing else: no build step, no database, no network beyond
localhost. `npm start` runs it and prints what it did. `npm test` runs it again and asserts the key
output. Each starter's README shows the expected output and walks through the code.

## Versions and CI

Each starter sets its `@cosyte/*` versions in its own `package.json` and commits its
`package-lock.json`. CI installs every starter from its lockfile and runs `npm test` on Node 22 and
24, on every pull request and every push to `main`.
