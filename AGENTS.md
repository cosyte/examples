# AGENTS.md

Runnable starters for Cosyte's `@cosyte/*` healthcare libraries. Each top-level folder with a
tracked `package.json` is one starter and its own npm project: a committed `package-lock.json`,
`src/`, `test/`, and a README. The repository ships no package: no root `package.json`, no
changeset, and no `CHANGELOG.md`.

## Build and test

Use Node.js 22 or later and npm. There is no build step, and nothing to install at the root.

```sh
cd deid-hl7    # any starter
npm ci
npm start      # runs the starter
npm test       # runs it again and asserts its key output, offline
```

## The gate

Run these from the repository root, in this order, before you push:

1. `bash scripts/check-no-emdash.sh`
2. In every starter, `npm ci`, then `npm test`. CI lists the starters this way:
   `git ls-files -- '*/package.json' | awk -F/ 'NF == 2 { print $1 }'`
3. Step 2 again on Node 22, the floor, for each starter the change touches:
   `mise exec node@22 -- npm ci`, then `mise exec node@22 -- npm test`.
4. `actionlint`, when the change touches `.github/workflows/`.

CI runs every starter on Node 22 and 24.

## Data

Synthetic data only. Every message, document, and image here is generated by `@cosyte/synth` or
written by hand, and must not pass for a real record. Real patient data never enters this
repository, a fixture, or a log.
